## 1. Common JavaScript Libraries

### 1.1 JQuery

JQuery is adept at dynamically creating HTML content that appears after JS is executed. If you scrape the page’s content by using traditional methods, you will retrieve only the preloaded pages.

### 1.2 Google Analytics

If a site uses Google Analytics or a similar web analytics system, and you do not want the site to know that it’s being crawled or scrapped, make sure to discard any cookies used for analytics or discard cookies altogether.

### 1.3 Google Maps

If you are scraping any location data, understanding how Google Maps works makes it easy to obtain well-formatted latitude/longitude coordinates and addresses.

## 2. Ajax and Dynamic HTML

- Ajax stands for *Asynchronous JavaScript and XML* and is used to send information to and receive it from a web server without making a separate page request.
- Dynamic HTML (DHTML) is HTML code, CSS or both that changes as client-side scripts change HTML elements on the page.

```python
from selenium import webdriver

import time

# Chrome driver installation path
CHROME_DRIVER_PATH = ChromeDriverManager().install()

chrome_options = Options()
# headless mode runs chrome without visible UI
chrome_options.add_argument("--headless")

# start chrome and open page

driver.get("http://pythonscraping.com/pages/javascript/ajaxDemo.html")

# waiting for page loaded
time.sleep(3)

print(driver.find_element(By.ID, "content").text)

driver.close()

```

### 3.1 Selenium Selectors

For both `find_element` and `find_elements` there are two arguments for them, `By` object and a string selector.

The `By` object specifies how the selector string should be interpreted, with the following options:

- `By.ID`: finds elements by their HTML ID attribute.
- `By.NAME`: finds HTML tag by their name attribute.
- `By.XPATH`: uses an XPATH expression to select matching elements.
- `By.LINK_TEXT`: finds HTML `<a>` tags by the text they contain.
- `By.PARTIAL_LINK_TEXT`: similar to `LINK_TEXT` but matches on a partial string
- `By.TAG_NAME`: finds HTML tags by tag name
- `BY.CLASS_NAME`: finds elements by class attribute.
- `By.CSS_SELECTOR`: finds elements by CSS selector

### 3.2 Waiting to Load

```python
# 13.6.py
# Waiting load

from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
from selenium.webdriver.chrome.options import Options
from selenium.webdriver.chrome.service import Service
from webdriver_manager.chrome import ChromeDriverManager

CHROME_DRIVER_PATH = ChromeDriverManager().install()

chrome_options = Options()
chrome_options.add_argument("--headless")

driver = webdriver.Chrome(service=Service(CHROME_DRIVER_PATH), options=chrome_options)
driver.get("http://pythonscraping.com/pages/javascript/ajaxDemo.html")

try:
    element = WebDriverWait(driver, 10).until(
        EC.presence_of_element_located((By.ID, "loadedButton"))
    )
except Exception as e:
    print(f"failed to load pages: {e}")
else:
    print(driver.find_element(By.ID, "content").text)
finally:
    driver.close()

```

### 3.3 XPATH

XPath (XML Path) is a query language used for navigating and selecting portions of an XML document.

The syntax has four major concepts:

- Root nodes vs. nonroot notes
  `/div` will select the div node only if it’s at the root of the document
  `//div` selects all divs
- Attribute selection
  `//@href` selects any nodes with the attribute href
  `//a[@href="xxx"]` selects all links in the document that point to xxx
- Selection of nodes by position
  `//a[3]` selects the third link in the document
  `//table[last()]` selects the last table in the document
  `//a[position()<3]` selects the first two links in the document
- Asterisk(*) match any set of characters or nodes and can be used in a variety of situations
  `//table/tr/*` selects all children of tr tags in all tables
  `//div[@*]` selects all div tags that have any attributes

## 4. Handling Redirections

```python
# 13.7.py
# Handling Redirection

from selenium import webdriver
from selenium.webdriver.chrome.options import Options
from selenium.common.exceptions import StaleElementReferenceException
from selenium.webdriver.common.by import By
from selenium.webdriver.chrome.service import Service
from webdriver_manager.chrome import ChromeDriverManager
import time

CHROME_DRIVER_PATH = ChromeDriverManager().install()


def wait_for_load(driver):
    for _ in range(20):
        try:
            driver.find_element(By.TAG_NAME, "html")
        except StaleElementReferenceException:
            return
        time.sleep(0.5)

    print("Timing out after 10s")


chrome_options = Options().add_argument("--headless")
driver = webdriver.Chrome(service=Service(CHROME_DRIVER_PATH), options=chrome_options)
driver.get("http://pythonscraping.com/pages/javascript/redirectDemo1.html")
wait_for_load(driver)

print(driver.page_source)

driver.close()

```
